## Never archive publicly

- API keys, tokens, `.env`, local credentials
- Author private notes and unrevised drafts
- Full manuscript LaTeX tree (unless journal policy explicitly requires it in the artifact)
- Fabricated results or placeholders presented as measured outcomes
- Indiscriminate copies of prior papers' frozen campaigns
